# 2D Action Game

## 概要
敵や障害物を避けながら、ジャンプで進んでゴールを目指す2Dアクションゲーム。初心者でも直感的に楽しめるよう、シンプルで分かりやすいUI/UXを重視して開発しました。

## なぜ作ったのか
2Dアクションゲームは、**操作の複雑さやゲーム画面の情報量が初心者にとってハードルになることが多い**と感じました。このプロジェクトでは「シンプルさ」と「分かりやすさ」を最優先に、以下を意識しました：

- プレイヤーの操作を「ジャンプ」に絞り、複雑な操作を排除
- 敵や障害物の動きをシンプルに、予測しやすく設計
- 画面に必要な情報だけを表示

プログラミング講師として「初心者がどこで詰まるか」を理解していることから、その知見をゲーム設計に活かしました。

## 何を重視したか
- **初心者向けの分かりやすさ**：シンプルな操作と直感的なUI
- **ゲームメカニクスの明確性**：「何をすればいいのか」が一目瞭然
- **短時間でプレイ可能**：0～5分で1ゲーム完結

## 主な機能

### 1. シンプルな操作体系
```
ジャンプキー：スペースキー
移動：左右矢印キー
```
初心者向けに、操作を最小限に設計。

### 2. ゴール到達型ゲームデザイン
- スタート地点からゴールまで進む
- 敵や障害物を避ける必要がある
- ゴール到達時にクリア画面を表示

### 3. 敵・障害物システム
- **敵**：一定の動きで移動、衝突するとダメージを受ける
- 衝突判定が明確で、初心者でも「なぜゲームオーバーになったか」が理解しやすい

### 4. リアルタイムフィードバック
- 現在のゲーム状態（プレイ中/クリア/ゲームオーバー）を画面に表示
- 敵との衝突時に視覚的なフィードバック

## 技術スタック
- **Unity**：2022 LTS
- **言語**：C#
- **対応プラットフォーム**：PC / WebGL

## 工夫した点

### 初心者向けの設計
初心者がアクションゲームで直面する課題：
- 「何をすればいいのか分からない」
- 「操作が複雑」
- 「死因が理解できない」

これらを以下で解決：

1. **操作の簡潔性**
   - 基本操作は「ジャンプ」のみ
   - 複雑な連携操作は排除
   - 初めてのプレイヤーでも3秒で理解できる設計

2. **視覚的なわかりやすさ**
   - プレイヤー・敵・障害物の色を明確に区別
   - 敵の移動パターンを予測しやすく設計
   - 衝突判定が直感的に理解できる

3. **短時間ゲームループ**
   - 1プレイが0～5分程度
   - 何度も挑戦しやすく、学習の機会が多い
   - 失敗してもすぐリトライできる

### コード設計
- `PlayerController.cs`：プレイヤー操作・物理制御
- `EnemyController.cs`：敵の動き・衝突判定
- `MainManager.cs`：ゲーム状態・ゲームオーバー判定
- など

各スクリプトの責務が明確に分離されており、拡張性・保守性を重視。

## セットアップ方法

### 必要環境
- Unity 2022 LTS 以上
- C# 9.0 以上

### インストール
```bash
git clone https://github.com/YourUsername/2DActionGame.git
cd 2DActionGame
```

### 実行方法
1. Unity Hub を開く
2. 「プロジェクトを開く」からこのリポジトリを選択
3. Unity エディタで `Assets/Scenes/Main.unity` を開く
4. Play ボタンを押してゲーム開始

## ゲームの遊び方

1. **ゲーム開始**
   - Play ボタンを押すとゲーム開始
   - プレイヤー（キャラクター）がスタート地点に出現

2. **ゴールを目指す**
   - ジャンプキー（スペース）でジャンプ
   - 敵や障害物を避けながらゴール地点まで進む

3. **敵・障害物の回避**
   - 敵に衝突するとゲームオーバー
   - 障害物に衝突してもゲームオーバー
   - わかりやすい色で敵・障害物を区別

4. **ゴール到達**
   - ゴール地点に到達するとクリア

5. **リトライ**
   - ゲームオーバー画面から「Retry」でリスタート
